# anime-amv-stylize

动漫混剪 / AMV / 概念 PV 的全流程工作流与风格化引擎 —— 一个 Agent Skill，加上它背后那份漫画风格背调包。

来自 **PROVANT**（Fate × SawanoHiroyuki[nZk]《PROVANT》）v1–v7 的七轮迭代：把一个"只放原片"的混剪，做成每镜都有风格层、卡点、逐词歌词和 HUD 的成片。

## 仓库里有什么

```
SKILL.md            入口：什么时候用、11 步流程、8 种风格层、硬规则
engine/             47 个 Python 模块 + MANIFEST.md（代码快照）
reference/          11 篇方法文档：流程 / 风格 / HUD / 转场 / 歌词 / 音频 / 配色 / QC / 审美日志 / 素材 / ER 后处理层
research/           PROVANT 漫画风格背调 v2：A/B/C/D 四分册 + 样张 + grokbot_G11
research/archive/v1/  第一版背调（已被 v2 取代，留档）
```

## 怎么用

**当 skill 用**：把整个仓库（或 `SKILL.md` + `engine/` + `reference/`）放进你的 skills 目录，Agent 读到 `SKILL.md` 就会按流程走。路径都相对仓库根目录，不需要改。

**移植 engine/**：`engine/MANIFEST.md` 写明了每个模块的作用和移植时要改的本机路径（素材盘、模型目录、字体）。

**只要某一种风格层**：直接读 `reference/02_looks.md`；HUD 看 `03_hud.md`，转场看 `04_transitions.md`。

## 流程（详见 `reference/01_pipeline.md`）

1. 立项：歌、时长、分辨率 / 帧率、素材范围、禁用项
2. 参考学习：量亮度、跳变、调色板，写"可借鉴 / 不能照搬"
3. 素材：conform → 切镜头 → 指标 → 打标签 → 镜头池
4. 节拍：自适应拍网格 + 人声分离逐词定时
5. 方向确认：3–4 张风格帧 + 两段 8 s 预览，**定了再做全片**
6. EDL：段落简报 → 自动选镜 → 每镜 look → HUD → 转场 → 歌词 → 台词
7. 分析（GPU）：抠像、检测、追踪、运动、强调色
8. 渲染：逐帧 `styled()` → NVENC 分块可续渲
9. 音频：原曲 + 同步原声 + 台词 → 限制器
10. QC：逐帧亮度查黑帧 / 闪烁（≤3 次/秒）
11. 交付：成片 + 改动清单 + 没验证的地方明说

## 背调包（`research/`）

2026-10-17 整理，给"漫画风格到底有多少种"这个问题做的底稿：

- **A 黑白技法**：网点、ベタ/ホワイト、线、カケアミ、效果线、コマ割り、风格谱系，以及搬到屏幕视频上的问题（57 个来源）
- **B 彩色印刷与动画纸面**：カラー原稿、2 色刷り、色更紙、Webtoon、原画 / 絵コンテ / 色指定 / セル画
- **C Fate 与影像参考**：各漫画版视觉资料、OP/ED/MV 里的"纸面"手法、5 套风格方案
- **D AE 实现笔记**：漫画风格链 v7→v8→v11 的实测与踩坑
- **grokbot_G11**：第三方 G11 风格包原件与试跑结果

每份文档都标了【事实】/【摘要】/【解读】/【建议】四级，来源可查。
