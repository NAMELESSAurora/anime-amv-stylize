# 01 全流程

PROVANT 的 v1 用 After Effects（ExtendScript 搭工程 + aerender 分段渲染 + 内存看门狗）。v2 起整条管线换成 **Python 引擎**（numpy / OpenCV / PIL + moderngl 着色器 + onnxruntime-directml + NVENC），因为：逐镜风格化需要逐帧算法（抠像、追踪、网点），AE 表达式做不了；GPU + 分块并行后 171 s / 2560×1440@60 全片约 20 分钟。下面以 Python 引擎为准。

## 1. 立项 → 写进记忆
歌（时长 / BPM / 结构）、分辨率帧率、素材范围（哪些系列、哪些剧场版目录）、用户喜欢 / 不喜欢的角色、禁用项（3D 素材、水印、某些版本）、交付习惯（自己审片还是交给用户）。

## 2. 参考学习（用户给参考帖 / 风格包时）
- 下载参考视频 → 逐帧 mean Y、ΔY 跳变数、每秒最多跳变、调色板、全局位移 → 表格。
- 每条参考写：手法 / 为什么有效 / 参数 / 实现方式；单列"不能照搬"（白闪、单帧黑闪、逐帧亮暗交替、镜头抖动、大面积饱和红、切碎五官）。
- PROVANT 学到的三条：hectoroz（版画 / 阈值调色板 / boil 线条 / 定格节奏）、Raf0x00（战术 HUD：气泡簇、三档线宽、光栅条、轨道排字、网格步进运动、克制撕裂）、causasui（星座节点追踪 + 标签、裁切框拼贴 + 标题条、像素块生长、边缘液化）。
- 用户给的漫画风格包（G11）：格外 AM 网点固定在纸面坐标、边→中心 smoothstep 渐变（0.45→1.15）、格内灰阶对比 1.1 + 轻颗粒、不做硬三级网点。

## 3. 素材
1. `probe_footage.py` 审计 → `conform_footage.py` 统一成 1440p mov（保留原帧率）→ `detect_letterbox.py` 量黑边。
2. `shot_inventory.py` 切镜头（场景检测）+ 指标 + 缩略图审片表 → 子代理按审片表打标签（`data/shots/tags`）。
   标签字段：who（不确定加"?"）、what、kind（战斗 / 宝具 / 特写 / 抒情 / 群像 / 空镜 / 日常）、grade A/B/C、usable、3D、水印位置、crop（缩放倍率 + 锚边）、dup_of。
3. `pool_v2.py` → 镜头池：过滤 3D / 不允许的系列；FAV（用户喜欢的角色）加分；gil（不喜欢的）减分；CROP 表处理水印 / 片商字样（例：1.11 倍锚上边裁掉底部字幕）。
4. **陷阱**（都踩过）：源镜头比槽短 → 被拉慢后跑进淡出黑场；源里有单帧闪黑 / 频闪；CM 片尾有制作字样；同一画面在不同视频里重复（相关 >0.92 去重）。

## 4. 节拍与能量
`adaptive_grid.py`：自适应拍轨 + 小节归组（不用单一全局相位）；`beat_verify.py` 核验；能量 → 每拍 impact（爆点、换气、段落）。卡点是 vibe：高能段 1–2 拍一切，抒情段 2–4 拍。

## 5. 方向确认（先小后大）
- `style_frames.py`：在真实帧上出 3–4 张风格帧（PROVANT：A 档案 / B riso / C 战术青 / D 漫画冲击页）。
- 两段 8 s 预览（平稳段 + 高潮段）跑完整引擎。用户点头后才做全片。

## 6. EDL（`edl_vN.py`，每版复制上一版再打补丁，文件头写清这版改了什么、对应用户哪句话）
- **段落简报 SEGS**：每段 b0/b1（拍号）、cuts（拍号切点）、kind（intro / battle / lyrical / punch / build / climax / breath / outro）、src（允许的源前缀）、hot（高潮）、pin（钉子：槽号或 "@拍号" → code / look / src_a / speed / hud / manga / tone / caption / poster…）。
- **选镜打分**：grade（A3 / B1.5 / C0.2）+ 1.6×prio + 1440 源 +1.2 + 喜欢 +1 − 不喜欢 6；kind 合段落 +0.9；时长够 +1、不够按比例扣；暗 −1.5、有内切 −2、和已用镜头相邻 −2.5；同源连续往后 +0.4、往回 −0.8；同源连 3 次就换源。
- **变速**：源够长 1.0×；不够按比例慢放，下限 1440 源 0.5×、1080 源 0.6×；前留 0.2 s 余量供转场。
- **look 分配** → **HUD 模板分配**（03_hud.md）→ **转场分配**（04）→ **slit 强调转场** → **歌词样式**（05）→ **台词列表**（06）。
- **闪烁预检**：按成片时间映射源亮度（48×27 灰度）：跳变 ≥30 计数、1 s 窗内 >2 加罚、黑帧 / 暗尾（y<16 且 p99.5<70）加罚 → 在可用源区间里滑动找最好的起点；还超标就换镜重排（钉子只警告）。
- **去重**：每镜 3 个采样帧 64×36 归一化相关 >0.92 → 非钉子的那个换掉。
- 产出：`data/edl_vN.json` + `EDL_vN.md`（人看的镜头表）+ `ae/qa/vN/<段>.jpg`（每段审片表：缩略图 + 镜号 / look / code / 转场）。

## 6b. 按角色分块的 EDL（`edl_v10.py`，PROVANT v8 起）
用户嫌"切得太碎、宝具 / 打斗被掐断"时换这种结构（拍点槽位选镜 → 角色块）：
- **BLOCKS**：每块 = 一个角色 / 一场打斗，t0/t1 落在段落拍上；items = 同一源里**连续**的池镜头（源片自己的剪辑点就是块内硬切）。
  选项：`s0/s1/take/tail`（取源区间）、`lo/hi`（用户标注的区间比池镜头长时放宽）、`w`（慢放权重）、`at`（锚：这个镜头从某拍开始，用来把飞踢 / 拳头 / 金剑对到歌词爆点）、`look`、`hud`（模板或 auto；R 不写 = `nohud`）、`who`（改写人物，HUD 资料和配色用）。
- **排时**：按锚点分段，每段"源时长 / 权重"摊到段长 = 整段一个速度（目标 0.85–1.15，慢唱段 0.5–0.7）；块内切点离拍 / 半拍 ≤0.09 s 吸到拍上。
- **HUD 少而准**：块开场、宝具、关键镜头才挂 HUD；其余 R 镜头 `nohud`（引擎只画 r_base 底色，分析时跳过前景遮挡图）。
- **转场只在块边界**：新角色进场用 slit（名字 + 职阶 / 日文名，全片不重复）；同角色两段之间 glitch_slam；冲击镜头（impact）直接硬切；固定段（片头、认可过的预览）沿用上一版的镜头和转场（同 id → 分析缓存直接复用）。
- **素材边界以用户标注为准**：用户标过"高价值区间"的 CM，先查标注再加镜头，别从片子别处猜角色；素材用尽就如实说"已全用"。
- 闪烁不再滑动（滑了块就断）：用 `timeline_flash.py`（成片帧 → 源亮度 160×90，R/P ×0.78，|ΔY|≥51、1 s >3 次 = 违规）找源内频闪 / 黑帧，按 `/tmp/lum` 式逐帧亮度把 s0/s1 收到干净区间。

## 7. 分析（`v2_preview.py KEY analyze`，.venv_gpu）
- 每镜：解码源（LiveSource，ffmpeg 限 4 线程）、强调色轨（AccentTrack）、镜头运动（LK + RANSAC 相似变换，累乘；离谱帧当不动）。
- R / P：目标框（脸→头→人检测，失败用 manual 框）+ 光流追踪；1/4 分辨率前景抠像（HUD 遮挡用）。
- Cd / Cb / Cs：每帧抠像（isnetis 1024，DirectML）+ 脸轨迹 + 星座节点；**漏抠修补**（覆盖率掉到前后 24 帧中位数 40% 以下、两边 30 帧内都有好帧 → 用好帧按镜头运动 warp 补）。
- M / B / A / G：只取脸位置（G 用镜头中间帧）。
- 缓存签名 = (code, src_a, speed, F_in, F_out, look, keep_x, hold)；改了才重算。新版本先把上一版 ana 目录整个复制过去。
- 并发：`ANA_JOBS=4 SEG_THREADS=2 DET_THREADS=2`；全片约 5 分钟。

## 8. 渲染 / 编码
- `RENDER_JOBS=5`（Windows 提交内存吃紧报 MemoryError 时降到 3，已完成分块会跳过，直接续渲）。
- 每块 360 帧 → NVENC HEVC 4:4:4 constqp 12（近无损）→ `encode` 拼接 + 原曲 → h264_nvenc p7 cq16 → `out/vN/`。
- 局部重渲：删掉受影响镜头所在的分块（帧号 //360，前后各留 12 帧转场）再跑 render。
- 2560×1440@60、171 s：渲染 18–22 分钟（5 进程）、编码 2 分钟、QC 3 分钟、EDL 3–5 分钟（闪烁预检 + 去重最慢）。

## 6c. 序章 / break / 尾声（`edl_v11.py`，PROVANT v9；成片比歌长）
用户："intro 可以不放歌先做点简短介绍然后再引入歌名和 title 在开始放歌"、"中间可以有一些 break 音乐淡出…再引入音乐"、"尾声淡出可以留长一点"。
- **song_map**：EDL 写成片时间；`cfg["song_map"] = [[成片起点, 歌起点, 歌终点], …]`。引擎 `prep()` 里 `_apply_song_map` 把拍点 / 歌词行 / 逐词时间 / 句尾覆盖整体平移（每进程一次）；
  builder 里歌曲部分仍按歌曲时间排（place / 吸拍 / 锚点不变），排完再用 s2f 平移；镜头终点在 break 处要按"终点"规则映射（不然跳到 break 后面）。
- **序章**：原声画面同源同步（原速），连续源段合成一条 native_audio；字幕 = 原声里的台词（核对过的标准文本，和转写对上才用）。
- **标题卡（look T，v6_title.title_card）**：静景压暗做底；kicker 解码 → 标题逐字从中缝弹出、字距收拢 → 色线 → 副标题 → 高光扫过；先在无歌里出现 ~1.5 s，歌从标题卡下进来，第一拍点切进第一镜（这里接 slit）。
- **break 落点**：找歌自己衰减到底、下一句清唱 / 强起的位置（PROVANT 77.2 衰减 → 78.53 IMPERSONATOR!）——停歌和回歌都"自然"；回歌那一下配 slit + 警戒线 + glitch 包络。
- **break 内容**：一段完整的高光片段（原速 + 原声，四段连续源，段间 gcut）；设计层：章节标题（左下，kicker / 大标题 / 日文副标题）+ "暂停中的播放器"（❚❚、进度停在歌的位置、均衡条压平；回歌时 ▶、跳动、滑出）。
- **尾声**：歌结束后让说话人把话说完（同一段独白的后两句）+ 原片环境音（那场戏自己的音轨，低电平长淡入淡出）+ 3 s 淡出。
- **停歌点**要落在"上一句唱完、下一句起唱之前"：查逐词时间（lyric_words），别只看歌词行起点（PROVANT："逆説" 97.94 起唱，行起点写的是 98.05）。
  歌在强拍上停时用磁带停转（最后 0.5 s 线性减速读源），回歌正好落在下一句的第一个字上。
- 跨 break 的歌词结束时间要截在本段末尾（引擎 `s2f_end`），否则一句歌词会挂过整个 break。
- 一个 break 里的片段"不用切"：整段源一条原声，风格只在源片自己的剪辑点上换（版画 / 美漫 / 漫画页 / riso 海报 / HUD 轮换），不遮场景。
- 混音：环境底和音乐等响时，每条环境底先 4:1 压（阈值 = 目标 -2 dB）、环境底总线 -7 dBFS 限制、原声总线 -3.5 dBFS 限制，音乐预让 4 dB；否则总线限制器会压到 -10 dB。
