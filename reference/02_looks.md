# 02 风格层库（每镜一种 look）

总原则（用户反复强调）：
1. **全局风格化**：每个镜头至少一种风格层，不出现裸原片段落（片尾可以例外用柔边保色）。
2. **细节不能糊、不能失真**：全分辨率处理；漫画格 / 卡片只缩小不放大取景；平涂只铺平坦区；原画描线和高频细节要回加。
3. **配色跟人物走**（07_color.md）；默认不橙。
4. 闪烁 ≤3 次/秒，不白闪；网点固定在屏幕 / 纸面坐标，不跟镜头动。

代码：`v2_looks.py`（R / Cd / Cb / P 基础）、`v3_manga.py`（M / B）、`v4_comic.py`（A）、`v4_looks.py`（G / slit）、`gpu.py`（着色器版本）、`v2_preview.py: styled()`（调度）。

---
## R — 战术 HUD 底（Raf0x00）
- 底：`r_base` 原色压暗 + 阴影冷色半调 + 细颗粒（hold 2 帧）；GPU 版同算法。
- 上面叠 HUD v5 模板（03_hud.md）。HUD 只占镜头前 ~60%（≥54 帧），之后分层收回。
- 冲击帧（impact）：前 3 帧换成版画 + 波形撕裂 + 48 根金色放射细线；slam：比例 1.22→1 指数缓出砸入。

## Cd — causasui 暗态星座
- 主角（抠像，脸所在连通域）保原色；背景 = 冷暗印刷灰阶（45° 网点 + 颗粒，hold 2）。
- 星座：人物轮廓均匀取点 + 脸中心 → 每点连最近 k 个，边依次画出（每条 8 帧）；节点强调色芯；前两个标签做色块。**不画坐标数字**（被评"无用信息"）。
- 抠像时间稳定：±2 帧平均，但先按镜头运动对齐、和当前帧 IoU < 0.8 的邻帧不参与（否则摇镜拖残影）；阈值 0.25–0.55、膨胀 5、软边 1.5。
- 漏抠修补（01 §7）。抠像几乎为空（<4%）就整帧进风格，不留空白。

## Cb — causasui 亮态档案页
- 纸灰底（向强调色偏 8%，Y≤150）+ 人物阈值灰阶 + 淡网格；从轮廓外种子点 Bayer 顺序生长像素块（避开脸）。
- 脸裁切框拼贴（标题条 + 引线），按两拍依次弹出；右上档案名条跟片源系列走。
- **裁切框里的源是空的 / 平的（std<9 或 mean<16）就不画框**（v4 的 0:27 两个空白框）。

## Cs — 柔边保色（抠像不可靠时）
- 不抠头：以人物中心轨迹（抠像质心，插值 + σ=10 帧平滑）为中心的大椭圆（0.36W × 0.62H，下移 0.10H），d<0.55 全保色、到 1 渐出；其余进 Cd 的暗态底。
- 用户原话："做不好的话可以放原片，或者不用完全将遮罩缩小在头部范围"。

## P — hectoroz 版画
- `poster_h`：阈值调色板（墨 / 金 / 米白），tension 模式整体压暗 20（换气段用）；`boil` 低频位移场每 2 帧换（定格也"活"）。
- 换气段：bars（上下黑边按 expo_io 收拢 0.10–0.11H）+ push 0.06–0.08 + 词墙歌词 → 用户最喜欢的"IMPERSONATOR"一刻，后来抽成了 slit 转场（04）。

## M — 日漫分镜页（`MangaPage`）
- 纸面：AM 网点 45°（13 px@1440），径向渐变 0.45→1.15 smoothstep，格内挖空；网点固定在纸面。
- 版式 `layout()`：
  - **band** 一条横幅（30%–70% 高）——抒情 / 空镜
  - **impact** 左大斜格 + 右上脸特写 + 右下强调格（+ 速度线）——战斗 / 宝具，≥1.0 s
  - **story** 上整幅 + 下三格右→左（前三格定格），≥1.6 s，特写 / 抒情
  - **slant** 上下两斜格
- 入场：每格 fk = 2 + 4k 帧砸入（1.12 回弹、60R 滑入、1.5° 回正），之后缓推 1.0→1.06。竖排明朝说明框逐字落下（≤8 字一列）；歌词行恰好从这镜唱起可进说明框（只存行号）。
- **tone**（v8 起默认 mono）：
  - `mono` 人物配色双色调：灰阶拉开（2–98 分位）+ 锐化 → 暗 = 角色暗色、中 = 主色、亮 = 亮色混纸 → 最暗 22% 叠 6R 网点 → 原画线压墨。
  - `duo` 双人对打：两色 riso 套印——A 色印暗部（实地 + 线）、B 色印中间调（15° 网点）、纸做高光；两人色相 <40° 时 B 换成副色。
  - `ink` 黑白（只留 1–2 页）：全分辨率轻高斯 → 分位数 → 阴影网点 + 细线。
  - `color` 全彩（被 mono 取代）。
- 取景**不放大**：`sw = max(W·vw/push, bw/push)`，缩小用 INTER_AREA，缓推的轻微放大用三次插值 + 轻锐化。早期半分辨率双边滤波 + 3× 放大裁切 = "人物轮廓和细节都糊了"。
- 频率：≥0.9 s 的槽每隔 6 镜一页（高潮 8 镜）；太暗的源不进（转网点会糊成一片）。

## B — riso 角色海报（`RisoPoster`）
- 红版（CLAHE 灰阶 → 15° 网点）+ 墨版（45° 网点 ∪ 原画线），12 fps 步进，入场两版错位滑入对齐；巨型 Bodoni 标题自下升起、红版错位影；打字机副标题；竖排日文名。
- 只放在**人声空档**（海报上不叠歌词）。

## A — 美漫（纵横宇宙式，`v4_comic.py`）
- 画面（v4 保真版）：
  - 原图提彩 ×1.15；8 色 Lab 色板（每镜固定）平涂只在纹理 std<6 的平坦区、权重 ≤0.22；
  - 暗面 Ben-Day（5R、0.24 强度）；高频细节回加 0.45；原画细描线 0.8 + XDoG 大轮廓 0.6；纸纹 0.4；
  - CMYK 套印错位**只在入场 8 帧**（常驻错位被看成失真）；10R 白边 + 黑框。
  - 一拍二（12 fps 换画）。
- 字：
  - 说明框 = 手裁不规则黄框（四角抖 ±7R、倾斜 ±4°）+ 品红错版影 + 青描边错版 + 框内细网点；名字 Comic Neue Bold 逐字蹦出（±3° / 基线抖）；右下黑底 Bungee 职阶小标。
  - 拟声字 = Bungee 逐字弹出（回弹 + ±9° 各自倾斜 + 上下错落）：斜向立体挤出（角色暗色）→ 9R 黑描边 → 角色色渐变 + 下半网点 → 青 / 品错版影；背后锯齿气球（白底 + 角色色网点 + 黑边）。
  - 拟声字按画面内容选：爆 / 炸→BOOM、交锋 / 火花→CLANG、斩 / 挥 / 剑→SLASH、光 / 宝具→FWOOSH，其余 KRAK；说明框只写核对过的真名 + 职阶。
- 用户指定不用美漫的角色（PROVANT：冲田总司、冲田〔Alter〕、宫本武藏、贞德）要排除。
- 失败史：Canny + 逐帧色相量化 → "太粗糙"；半分辨率平涂 → "像奶油一样化开"；常驻套印 → "失真"。验收方法：和源并排裁大图对比（mean abs diff 应 ≲20，脸 / 眼 / 发丝要一致）。

## G — Fate 灵基卡（`saint_graph`）
- 背景：本镜画面半分辨率 σ1.6 轻模糊 × 0.5 + 角色主色径向光（"背景也要有比较清晰的内容"）。
- 卡：每个角色专属卡框（生成素材，10_assets.md）→ **风格化**（亮度→角色配色渐变映射 72%、暗部网点、细扫描线；"展示原边框很容易暴露素材缺陷"）→ 中央透明窗按脸裁竖幅画面 → 金属高光扫过一次。
- 尺寸：卡高 1.12H、顶对齐（顶饰完整，底边出画）。
- 动效：入场 10 帧 glitch 切片拼合 + RGB 分离、横向 0.55→1 回弹；之后每 36 帧一次 4 帧小 glitch；常驻 2 px RGB 分离；上浮 + 轻呼吸。
- 左侧信息块（HUD v5 字阶）：SAINT GRAPH / 职阶巨字 / 真名 / 日文名 / 六项参数 / 宝具读音 + 日文名 + 等级·种类——全部来自核对过的资料。
- 可在角色**开口说台词**的镜头上用（PROVANT 开场贞德：卡里同步口型）。

## 全局层
- **glitch 包络** `(t0, t1, a0, a1)`：蓄力爬升 → 换气冲顶 → 爆点 8 帧落回；外加强拍短脉冲（能量 ≥0.48、间隔 ≥1.5 s、0.55→0 / 8 帧）。glitch = 横切片错位 + RGB 分离 + 少量信号丢失条（亮度基本不变，不算闪）。
- **片尾淡出**：每帧 ≤ 约 4 亮度。
- **颗粒 / hold 2**：静态纹理两帧一换，避免 60 fps 下发"沸"。

## 电影质感 + 21:9 遮幅（v7_cine，PROVANT v10 break 段）
用户："break 时…画面动态调整为 21:9，并且去掉两个 break 片段的点状纹理，改为电影质感滤镜（增强特效和质感）"。
- 整帧（镜头 + HUD + 转场 + glitch）之后、歌词 / 字幕之前做；EDL `cine=[{t0, t1, bar_in:[a,b], bar_out:[a,b]}]`，强度和遮幅一起 smoothstep 进出。
- 镜头 `cine=True` 时 R 底直接用原画（不走 r_base 的压暗 + 冷色网点）；漫画页 / riso **保留**，只是网点换连续调（`MangaPage(smooth=True)` / `RisoPoster(smooth=True)`）——用户纠正过：要换的是纹理，不是风格。取景器 HUD 在 cine 段不画自己的遮幅、文字贴遮幅内沿。
- 组成：S 曲线 35% + 黑位轻抬 + 高光肩；受控辉光（亮度 > 0.62，1/4 分辨率两档高斯，屏幕混合）；横向光条（同一亮部只做水平长模糊，冷白，很淡）；
  边缘色散（R / B 绕中心 ±0.16%）；暗角 16%；每帧换的细颗粒（半分辨率高斯噪声 → 轻模糊 → 双线性放大，中间调最强）。
- 21:9：2560×1440 每边 171 px；进 break 时等缝转场打开后 0.75 s 收拢，回歌前 0.6 s 打开。播放器小窗正好落在下遮幅里。
