# 04 转场库（v2_trans.py / v3_hex.py / v4_looks.py；调度在 v2_preview.render_frame）

用户要求："转场的 motion 要华丽"（参考 mg-styles-15、prompt-motion.com）；splash "太粗糙"——不用；glitch 认可并要求"多加一点"；"IMPERSONATOR 这个缩窄画幅然后强调文字的转场我很喜欢"；"不要让主画面和取景框空着"（不要黑画面转场）。

| kind | pre / post 帧 | 做法 | 用在 |
|---|---|---|---|
| gcut | 2 / 3 | 切点前后各几帧 glitch（切片错位 + RGB 分离，amp 0.7） | 1 拍一切的密集段（v9 起全部用它，不留硬切） |
| glitch | 5 / 6 | 同上 amp 1.0 | 一般切换 |
| glitch_slam | 4 / 8 | glitch + B 砸入（比例 s0→1 指数缓出） | 能量 ≥0.6 的拍、B 是 R / P |
| hex | 9 / 9 | EVA 蜂巢翻转：全屏平顶六边形格（64R）按离动机点（A 的目标框中心）的距离 + 抖动依次翻 A→B，翻转中 3 帧亮强调色 65%、刚翻完的格描亮边 6 帧淡出 | 进出漫画页 / 海报、抒情段 |

| lock_zoom | 12 / 6 | 锁 A 的眼睛一带：角标咬住窗口、B 在窗口里抖点解码，再从窗口穿过去 | A 是 R / P 且 ≥50 帧 |

| whip | 6–7 / 6–7 | A、B 并成横幅甩过去，方向模糊跟速度、接缝最糊（切点在模糊峰） | 一般 / 漫画页 |

| cut | — | 硬切 | 冲击帧（impact / 换气 bars）前后；QC 需要时 |

## 分配规则（assign_trans + add_slits）
1. B 是冲击帧 / 换气段，或 A 是换气段 → 硬切（冲击帧自己就是转场）。
2. B 是 Cb 且两边 ≥30 帧 → panel_slap。
3. 两边任一是漫画页 / 海报 → 轮换 hex / whip / glitch / grid / hex / gcut（≥36 帧），否则 gcut。
4. 抒情 / 片头 / 片尾段 → 轮换 lock_zoom / hex / grid / whip（≥40 帧），否则 whip / gcut。
5. 1 拍一切（<40 帧）→ gcut。
6. 能量 ≥0.6 且 B 是 R / P → glitch_slam。
7. 其余轮换 glitch / hex / whip / lock_zoom / grid / gcut / cut。
8. add_slits 覆盖：切到新登场的关键角色 → slit。
9. NO_TRANS：QC 发现某个转场叠加源内闪烁会超 3 次/秒 → 那里改硬切。
目标比例（PROVANT v7）：gcut 75、hex 14、grid 12、glitch 12、whip 11、slit 7、panel_slap 7、lock_zoom 2；硬切 11%。

## 陷阱
- 转场两端的源都要有画面：源镜头太短被拉慢 → 尾巴进了淡出黑场 → 转场是黑的（v4 0:27）。EDL 闪烁预检把"暗尾"算进罚分。
- 进漫画纸面 / 海报这种亮底时，whip 的暗中间帧 + 源内闪光会叠成 4 次/秒；QC 后改硬切或改 hex。

## 警戒线（v5_tape.py，PROVANT v8；用户："人物转场除了人物边框外还可以加一些警戒线等画面处理方式"）
- 胶带 = 角色签名色底 + 45° 黑色危险斜纹段，与文字段交替（⚠ CAUTION / 真名 / CLASS 职阶 / 日文名——只写核对过的）；两端随机锯齿撕口；反色大字条（黑底 + 角色色字）。
- **slit 模式**：两条胶带斜跨上下黑边（像被封锁的门缝），缝里的名字不挡；切点前 10 帧甩入，缝张开时被扯走。全片每个 slit 都带。
- **cross 模式（kind="tape"，pre 10 / post 24）**：A 段两条交叉胶带甩入 → 切点一顿（2 帧抖 + RGB 错位）→ 切后第三条大字条拍入、B 从 1.04 落回 → 沿各自方向扯走（方向交替）。用在同角色续段 / 已出过 slit 的角色再出场。
- 融入画面：投影（σ6R、偏 8R/10R、45%）、沿轴向运动模糊（速度 × 0.55，≤140R）、胶带在时画面压暗 12%、文字段慢速滚动。
- 颜色 = **名字对应角色**的签名色（EDL 里 tape_col），不跟入场镜头走（冲田的胶带曾被冲田〔Alter〕镜头染红）；地名（CAMELOT）用该篇主角色。
