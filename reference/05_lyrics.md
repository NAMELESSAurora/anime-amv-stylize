# 05 歌词：逐词定时 + 排版

## 版权
用户给的歌词包（PROVANT：日英原文 74 句已对轴）只放在 `research/lyrics_user/`；数据文件（lyric_words.json、EDL）只存**时间 / 行号 / 切词结果**，引擎渲染时才从用户包读原文。漫画说明框要放歌词时 EDL 里只写 `caption_lyr = 行号`。

## 定时（lyric_time.py）
1. 人声分离：`sep_mdx.py`（UVR MDX-NET Voc_FT onnx，N_FFT 7680 / HOP 1024 / DIM_F 3072 / DIM_T 256，DirectML）→ 干声 wav。
2. 干声起音包络：onset_strength 150–5000 Hz、hop 128 @22.05 kHz（≈5.8 ms），peak_pick 出候选。
3. 每句：词数、音节估计（英文元音组，词尾不发音的 e / ed 减 1；日文假名 1、汉字 1.6、小假名 0）→ 期望起点；动态规划在候选起音里选单调路径（含第一个词，窗 −0.15…+0.35 s）：得分 = 1.5·强度^0.7 − 1.2·|偏离| / 平均词长，跳过罚 0.8，相邻 ≥0.09 s，保留前 60 条路径。
4. 视觉领先 1 帧。
5. **慢唱 / 拖长音的句子必须人工核**：字幕轴常常把整句压短。用 pyin 音高 + 起音峰逐 0.1 s 打印，按"每个新音高 / 新起音 = 一个词"定。手工值写进 `MANUAL`，句子显示结束写进 `END`（lyric_end.json 覆盖字幕轴）。
   - PROVANT 第 12 句 "JUST LIKE ALL THE REST?"：第一次按音高细节定（过快）→ 用户说每词约 2 s（过慢，抢拍问题其实是字幕轴太短）→ 最终每词约 1.2 s，按起音峰 28.15 / 29.2 / 30.5 / 31.7 / 32.7，REST 尾音拖到 34.6。教训：**用户给的时长是听感描述，最后还是落到干声起音峰上**。

## 切词（burst_words）
- 英文：虚词（THE / AND / A / OF / TO …）挂到下一个实词上（最多两个）；慢唱句一词一出（BURST 覆盖表）。
- 日文：按助词切短语（の を が に は で と へ も や），汉字串不拆。

## 样式（lyric_map）
- **burst**（英文 hook、高潮句）：一次一个词、巨大、空心描边入场 3 帧 → 实心落地；避脸（人物框上 35% 当头，三档高度挑重叠最少的）。
  - hot（高潮）：先 2 帧乱码解码、回声拖尾 3 层、每拍脉冲（1.04→1 + 色散 + 切片）、强调色荧光条、碎裂退场；峰值词加**词墙**（整屏空心描边行反向滚动）。
  - 慢词（词长 ≥0.45 s）：9 帧慢入场（1.18→1 渐显、轻色散）+ 唱的过程中横向慢拉 7%（字距感，表现拖长音）。
  - 爆点（punch）时刻再砸一次 1.3→1。
- **serif_dark / serif_ink**：明朝逐字升起（16R、12 帧、字间 2 帧）+ 投影；暗底白字 / 纸底墨字。
- **hud**：黑底标签条 + 解码出字 + 左侧强调色竖条；位置避开 HUD 信息块。
- **caption**：已进漫画竖排说明框，不再单独画。
- 海报（B）上不叠歌词 → 海报只放人声空档。
- 已去掉：burst 词下方的 "01/05 LYR 12 T+…" 计数小字。
- 仍在代码里（PROVANT v7 为止）：serif 样式下的 "LYR 12 // 28.13 — 30.98" 和 hud 样式的 "LYR 12 // DECODE 80%" 小字——按"去掉无用信息"的原则，新项目里应该删掉（v2_preview.lyric_layer、v2_looks.lyric_hud）。

## 台词演出字幕（v6_title `style="line"`，PROVANT v10）
- 说话人牌：角色色短条从外侧生长 → 英文名字距收拢 → 日文名上浮 → 芯片（回忆 = MEMORY），比第一个字早 9 帧。
- 正文：明朝体，每个字在被说出的时刻出现（ASR 词级时间按字数摊开；标点跟前一字 +0.04 s）：10 帧透明度 + 上浮 18 px + 角色色残影收拢；下方进度线跟着念。
- 喊招（shout）：粗黑体（YuGothB）每字 5 帧从 1.5 倍砸下 + 前 6 帧抖动 + 双色错位描边。
- 退场：末 18 帧逐字（左→右错 1.2 帧）上浮淡出；整块压柔和暗影（alpha 膨胀 + 模糊，只在字周围），亮画面也读得清。
- 位置：说话人在画面哪边就放哪边（对话两人分左右），避开章节标题 / 播放器 / HUD 读数块。
- **文字核对**：去配乐干声上跑两个 ASR（faster-whisper medium + large-v3），原声 / 去配乐各一遍；只用一致的部分，同音字按上下文（彗星 / 円卓 / 測る）；
  说话人用逐词 pyin 基频（男 90–140 / 女 190–250 Hz；喊叫会偏高，pyin 有倍频错，只作参考）+ 口型 + 画面谁在场；对不上的句子不上（例：魁札尔段 "勝利を!" 其实是立香在喊）。
- 只放在不唱的地方（break 原声段 / 歌里的器乐段）。
