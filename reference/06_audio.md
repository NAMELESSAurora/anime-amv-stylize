# 06 音频：原声、台词、混音

## 原则（用户原话）
- "成片可以适当加一点原声"。
- "台词可以多加一些女性的台词"；"现有的台词插入很浑浊而且不用刻意压低音乐，并且台词声音可以适当大一点"。
- "台词还是很浑浊并且有些不明意义以及对不上人物，例如片尾马修的台词是贞德的"。
→ **宁少勿错**：每句台词必须能确认说话人、句意完整、只放在不唱的地方、配在说话人出现的画面上。

## 原声事件（v2_audio.events，v3_audio 复用）
- 只取正片 / 战斗剪辑的原声（OP / ED / PV 自带别的歌，不用），按画面同步取（src_t 映射，只取 1.0× 镜头）。
- hit（爆点：源里最强瞬态对齐到爆点）、rise（换气段：爆点镜头前一段蓄力声）、accent（高潮冲击镜头开头）。
- 音乐本身已经顶满（局部 RMS > −11 dBFS）的地方，音效降到 −18 dB 只做质感（否则限制器把爆点压下去）。

## 台词采集（dialog_harvest.py）
1. 人声分离（MDX Voc_FT）→ 干声。
2. Silero VAD（v5 onnx，512 样本 / 32 ms）→ 语音段（0.5–4.0 s，前后 8 帧要有停顿）。
3. pyin 基频中位数 > 185 Hz 判女声（喊叫的男声也会偏高，所以还要看画面 / 文本）。
4. faster-whisper small（ja）转写（只用于挑句，不上屏、不当真理）；记录 logprob / no_speech。
5. 候选写 `data/dialog_candidates.json` + 每句 wav。

## 说话人匹配（关键）
- 把候选的源时间区间和镜头池对上：**说话时画面上是谁**（镜头标签 who）。全程同一个人在画面上才算可信（例：FGO 终章 PV 85.9 s "未来を取り戻す物語だったでしょ" 画面全是贞德 → 贞德）。
- 放置：配到成片里同一个人出现的镜头；最好直接用说话那段源画面、1.0× 同步口型（PROVANT 开场：贞德灵基卡里同步说话）。
- 连续几句同一人（马修三句"どうか忘れないでください / 多くの出会いと / 多くの未来"）可以组成片尾画外音。

## 放置：只放在不唱的地方
- 歌词字幕轴上的"空档"不等于没唱：用干声 pyin 逐 0.1 s 扫音高——有音高 = 在唱（PROVANT 31–38 s、100.5–102.7 s 实际在唱，台词放进去就"浑浊"）。
- 干声无音高、只有起音的段（打击 / 人声切片）可以放短句，但要提醒用户听一下。

## 混音链（v3_audio.py）
- 音乐先让 2 dB（母带到 0 dBFS，重采样后有 +0.9 dB 样间过冲），限制器只抓叠加的瞬态。
- 台词：高通 90 Hz ×2、300 Hz −2.5 dB（去闷）、3.2 kHz +3.5 dB（咬字）、11 kHz 低通（磨掉分离残留的"水声"）→ 拉到目标电平 → 4:1 压缩（阈值 = 目标 −3 dB，3 ms 起 / 100 ms 放）→ 补偿 → 台词总线 −5 dBFS 前瞻限制。
- 目标电平：比所在位置音乐 RMS 高 7 dB，限在 −15…−9 dBFS（安静的片尾也不低于 −15）。
- **不 duck 音乐**；台词响时只把音乐的中置声道（M）250–4500 Hz 挖低 6 dB（零相位分频，M_band + M_rest = 原 M；S、低频、高频不动）——听感上音乐没变小，人声有了位置。
- 总线前瞻限制 −1 dBFS（5 ms 预看、60 ms 释放）；报告最大增益衰减和 >1 dB 的总时长（PROVANT v7：1.4 dB / 0.19 s）。
- 合成：视频 copy + AAC 320k。

## v4_audio.py（PROVANT v9，成片比歌长）
- 歌按 song_map 分段贴（第二段 20 ms 淡入；第一段 300 ms 淡出，落点选在歌已衰减到底的位置）。
- native_audio：序章 / break / 尾声的原片整轨，按有声 RMS 归一（咏唱 -14、break -13、标题卡夜风 -24、尾声环境 -27 dBFS），段间 40 ms 交叉。
- 环境底（用户："可以加上一些原片的环境音"）：歌段里正片源、速度 0.88–1.12、非步进的镜头，同步取原声，高通 150 Hz，-31 dBFS（歌安静处 -27），40 ms 交叉；
  台词 / 原声段 / 爆点音效附近不放。PROVANT v9：51 个镜头。
- 爆点音效不能和原声段重叠（换气段的 rise 会预放 break 开头那段原声）。
- 台词目标电平按"音乐 + 原声"算；歌结束后的台词落在 -15 dBFS 下限。
- 选环境音：先量频谱平坦度（噪声型 > 0.4、乐音型 < 0.15）和有没有人声（VAD），再用。

## v10（PROVANT v10，用户 10-20）：去配乐 + 同源去重
- "能不能将素材里的音乐和环境音人物音剥离？仅保留人物音和环境音" → `sep_bandit.py`：BandIt v2（DnR v3 多语）音乐分支 ONNX（models/bandit，
  CC BY-SA 4.0 权重 / Apache-2.0 代码，哈希核对），onnxruntime-DirectML，8 s 窗 / 2 s 步 Hann 交叠；按需缓存（只分离混音实际读到的源区间 ±4 s，index.json）。
  - **不要直接"原声 − 音乐估计"**：复数掩码有相位误差，合成测试（歌 + 干声等响）SDR 只有 0–3 dB；改成逐声道算掩码、按幅度做维纳软掩码
    `w = |X−MU|² / (|X−MU|² + 1.5·|MU|²)`：6.5–8.9 dB（干声比音乐低 8 dB 时 5.5 dB）。验证法：已知干声 + 已知纯音乐合成，量 SDR。
  - 第二遍分离没用（有些窗电平反而变大）。
  - 去配乐后纯环境段（原来大半是配乐）会变得很轻，归一化别硬拉：环境段增益封顶 +6 dB。
- 同一段源声音全片只出现一次（用户："冲田总司的片段语音存在重复"）：`bed_reads` 先把台词源区间（±0.15 s）、原声段源区间、CM 旁白区间占住；
  原速镜头同步取自己的源区间（跳过已占）；慢放镜头（画面和声音本来不同步）同源首尾相接的接着往下读、跳过已占、凑够时长。
  台词所在的成片时间不垫环境底（去配乐后环境底里也有人声，会叠成两句）。交付前跑一遍"同源区间重叠"审计（native / 台词 / 爆点 / 环境底两两比）。

### v10 第二版（用户看过 v10："素材原声不用单独提取环境音和人声（这样会导致失真），将原声的背景音压低一点"；"角色的语音有些失真"）
- **默认不完全去配乐**：`sep_bandit.bg(yid, t0, dur, bg_db=-6)` = (1−g)·去配乐 + g·原声（维纳掩码是线性的，等价于把配乐那部分压低 |bg_db|）。
  去配乐段和原声段必须同一次解码、同起点（缓存 *_orig.wav），否则相加会梳状滤波。合成测试：背景 −6 dB 的残留失真比完全去配乐低约 7 dB。
- 用户点名"按原声放"的段（魁札尔 break）：原样，只做静态增益（峰值封顶）。
- **失真的真正元凶**：压缩 / 限制增益按 48 样本一阶一阶跳（压 13 dB 时每毫秒跳 2 dB）+ 4:1 / 3 ms 快压。改：块增益逐样本插值；台词 2.5:1、6 ms 起 / 160 ms 放；
  `level()` 把一段放到目标电平、平滑前瞻限制，限制量超过上限（台词 5 dB、原声 4 dB）就把目标往下让 1 dB 再试——宁可小声一点，不硬压。
- 动画对白峰值因子 16–18 dB：硬拉到 −9 dBFS 必然要压 10 dB 以上；压在歌上的台词靠 M 声道 250–4500 Hz 挖槽（8 dB）让位，而不是靠响。

### 衔接（用户："原声的音乐被处理的断断续续…跟歌曲的衔接也很突兀，戛然而止或者突然出现"）
- 先量再改：各总线单独存（`DUMP_STEMS=1`），在每个交接点前后 ±1.2 s 打 100 ms 包络（歌 / 原声 / 总和），找"总和掉到无声"或"0.1 s 内 +20 dB"。
- 歌 ↔ 原声必须**重叠**交叉（等功率 sqrt(smoothstep) 曲线）：歌在停歌点前 1 s 淡出、原声能提前就提前进来（源从 0 s 起就只能淡入 0.5 s）；
  回歌时原声越过回歌点再放 0.5–0.6 s，歌提前 0.6 s 淡入。原来"原声在回歌点前淡完 + 歌 0.3 s 淡入"中间会掉成无声。
- 垫在歌下的短片段（环境底 / 爆点音效）里的原片配乐会随切点一开一关：压 -18 dB；去掉配乐后只剩残渣（比原声低 9 dB 以上）的片段不垫；
  连续片段 80 ms 交接，每串首尾 0.3 s。PROVANT：55 段里 23 段被跳过，环境底开关从 15 次降下来。
- 遮罩"抽动"不是主因：背景 -6 dB 时残留配乐的 50 ms 增益波动只有 0.6–1.5 dB，时间平滑遮罩帮助不大还伤人声，不做。
- 用户点名要"清晰的人声"的台词（PROVANT：开场贞德、片尾马修，"参考 V7"）：用 MDX 分离干声 + 11 kHz 低通（v7 做法），不是原声压背景；
  句尾读 ≤0.35 s 干声余音再淡出（不读进下一句）。
- 选"环境音"前先量：去掉配乐后电平掉 15 dB 以上、频谱平坦度 ~0.02（乐音）→ 那其实是配乐，不是环境声。动画 PV / 剧集的场景几乎都铺了配乐，找不到干净环境声时宁可留白，别把配乐当环境底。

### 无歌序章 → 歌的衔接（用户："完全去掉素材原声的音乐又显得人物干声很粗糙，但是保留音乐会和歌曲衔接有些突兀"）
- 先量：分离模型认不出配乐的场景（去配乐前后电平一样），用原声，别用分离干声（干声发干、发毛）。
- 歌没有前奏、第一拍直接砸进来时（PROVANT：0.2 s 就 -21 dB、80% 能量 < 300 Hz），从静音切进来必然突兀。做法（v4_audio）：
  `recede()`：台词说完后原声低通从 12 kHz 扫到 500 Hz（退远）、混响逐渐长出来（算法混响 RT60 3.8 s），干声段尾淡完、混响尾巴越过段尾；
  `song_intro()`：用歌自己第一拍做混响、只取湿声倒放 1.8 s，末尾对齐第一拍（从无声升起来、第一拍变成"落地"）；头 0.7 s 从 300 Hz 高通版渐变回全频，第一拍带 1/3 低音落地。
  量包络确认中间没有掉进无声（PROVANT 最低 -41 dB、约 0.25 s）。
