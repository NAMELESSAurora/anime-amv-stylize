# 07 配色系统（palette.py、hud_v5.make_pal、v2_looks.AccentTrack）

用户原话："取景框不能只是橘色的，要根据画面主色进行变幻"；"HUD 的配色要根据画面和角色的配色来变"；"少用橙色配色，你要根据人物配色来选择风格化配色"。

## 三层
1. **画面主色轨**（AccentTrack）：每帧色相直方图（饱和度加权）取主峰 / 次峰（相距 ≥60°）；色相指数平滑（最短弧，τ≈20 帧）；几乎无彩色的帧（黑白 / 灰夜景）用冷钢蓝（不再用锈橙）。产出 main / hi / dk / sec / txt。
2. **角色签名色**（palette.CAST：who 字段第一个名字正则匹配 → (主色, 副色)）。例：贞德 金 + 深蓝，阿尔托莉雅 蓝 + 金，Saber Alter 暗红 + 灰紫，冲田 青 + 樱粉，冲田〔Alter〕红 + 灰，武藏 蓝 + 朱，美杜莎 紫 + 品红，迦尔纳 金 + 红，莫德雷德 红 + 银，玛修 薰衣草 + 粉，理查 红 + 金；士郎 红 + 青、凛 红 + 黑、黑樱 洋红 + 紫……新项目按角色设定图补表。
3. **合成（每镜在 styled() 一开头替换 acc）**：
   - 认得出人物：签名色和画面主色色相差 ≤60° → 62% 签名 + 38% 画面（跟着画面走）；冲突 → 只用签名色（混出来是脏灰）。
   - 认不出人物：画面主色落在橙区（15–48°、饱和 >0.35）→ 换成画面副色；副色也橙 → 冷钢蓝。
   - 饱和度夹到 0.50–0.90、明度 ≥0.86（低饱和的白 / 银角色保持低饱和）；txt 按主色亮度选黑 / 白。

## 吃这套颜色的层
HUD 全部元素、Cd 星座节点、Cb 标题条 / 像素块、漫画 mono 双色调 / duo 两色、美漫拟声字渐变 / 立体 / 气球网点 / 职阶小标、灵基卡框配色映射与背景光、歌词荧光条 / 描边色散、转场（hex 翻格色、slit 缝口线、grid 条边）。
