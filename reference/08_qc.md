# 08 QC、源陷阱、性能

## 成片 QC（qc_v1.py）
- ffmpeg 缩到 160×90 灰度读裸流 → 逐帧 mean / p99.5。
- 黑帧：mean < 4 且 p99.5 < 24。片尾淡出最后几帧是允许的黑帧，其余一律修。
- 闪烁：|ΔY| ≥ 51 记一次跳变；任意 1 s 窗内 >3 次 = 违规。
- 违规定位：打印违规窗口内每次跳变的时间、前后亮度 → 对照 EDL 找镜头 / 转场 → 判断是源内闪光、源内闪黑帧，还是转场叠加。
- 修法优先级：滑动源起点避开闪光 / 黑帧（钉住新的 src_a、收紧 hi）→ 那个转场改硬切（NO_TRANS）→ 换镜。
- 局部重渲：删相关分块 → render（续渲）→ encode → mux → 重跑 QC。

## EDL 级预检（每版都跑）
- flash_check：按成片映射的源亮度（48×27）：跳变 ≥30、1 s 窗 >2 加罚、黑帧 + 暗尾加罚；超标先滑动，再换镜。
- dupes：3 个采样帧 64×36 归一化相关 >0.92 → 去重。
- BAN：QC 抓到的坏镜头（源里频闪、葡语字幕等）加进黑名单。

## 源陷阱清单（PROVANT 踩过）
| 现象 | 根因 | 修 |
|---|---|---|
| 转场 / 镜头黑画面 | 源镜头比槽短，被拉慢后进了淡出黑场 | 预检把暗尾算罚分；换长源 |
| 1 秒 4 次闪 | 源里一帧闪黑（3.144 s）+ whip 进亮纸面 | 钉 src_a / hi 避开；改硬切 |
| 档案页空白框 | 裁切框落在淡出 / 无脸区域 | 框内 std<9 或 mean<16 不画 |
| 片尾头发若隐若现 | isnetis 连续 15 帧整帧漏抠（CPU / GPU 都一样）+ 摇镜时邻帧平均拖残影 | 漏抠修补 + IoU 加权对齐平均；最终用 Cs 柔边 |
| 水印 / 字幕 / 制作字样 | 源自带 | crop（缩放 + 锚边），先在原帧上画裁切框确认 |
| 同画面两次出现 | 不同视频里同一镜头 | dupes |

## 性能 / 稳定性（Windows）
- 提交内存不够（MemoryError / commit limit）：ffmpeg 解码 -threads 4、用完关解码器、RENDER_JOBS 5→3、ANA_JOBS 4。已完成分块自动跳过，直接续跑。
- GPU：.venv_gpu（system-site-packages + onnxruntime-directml）跑 isnetis / YOLO / MDX / VAD；moderngl 着色器做 r_base / c_dark_base / over / compose / hud3；NVENC 编码。分割 0.45→0.05 s/帧，合成 0.80→0.17 s/帧，HUD 1.0→0.13 s/帧。
- 停后台渲染：停任务后还要按命令行查残留 python 进程（`v2_preview.py <KEY>`）并结束，否则旧进程还在写分块。
- 编码输出目录按 KEY 映射（V5→v3 …）；新 KEY 忘了加映射 → 写进错的目录、mux 找不到文件。
- numpy 负数开小数次方会出复数（hexwall 的 near 因子出界）→ 所有比例因子先 clamp 到 0..1。

## 亮度阻尼（damp，PROVANT v9）
用户要求"不用切"的整段里，源自己有黑白骤变（白底 → 黑烟）时：镜头标 `damp`，渲染时该镜头（前后各 2 帧）里亮度跳变 > 30 的帧和上一帧按 0.3–0.6 混合（3–4 帧光拖尾），跳变压到 51 以下；不剪画面、不换风格。
