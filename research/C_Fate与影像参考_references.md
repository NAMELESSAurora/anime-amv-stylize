## 0. 先读：对现有方案里一条描述的更正（事实）

`AMV_DESIGN_PLAN_v1.md` 第 01 节写着：「官方动画 OP 的视觉方向被描述为生硬线条、黑白冲击帧、大量碎屑作画」。

- 本次能找到的这类描述只有 Visual Otaku 2026-01-06 的一篇文章。文中写的是 "black-and-white flashes of raw impact"、debris acting、"You can see the pen strokes"、"a gritty cloud of ink"，但**说的是 TV 正片整体，全文没有提到 OP 或 PROVANT**。[核] https://visualotaku.com/reviews/fate-strange-fake-visual-analysis-ufotable-vs-a1/
- 官方无字幕 OP 的已知职员：分镜为两位系列监督榎戸駿、坂詰嵩仁，单元导演（unit director）为岩澤亨。[核] https://anitrendz.net/news/2026/01/10/fate-strange-fakes-opening-now-on-youtube/ ，视频：https://www.youtube.com/watch?v=tcC9g9dlv58
- [目视] 项目里已有一张 OP 接触表（`sheets/Fate_strange_Fake_OP___Opening__PROVANT_...jpg`，30 个采样格，缩小副本为 `ref_img/_internal_sf_op_contactsheet.jpg`）。采样格**以彩色为主**：红黑高对比、蓝天、森林、城市街景，**没有看到黑白漫画式的画格**。采样太稀，不能据此断言 OP 里完全没有黑白帧。
- **结论**：「黑白冲击帧 / 碎屑 / 笔触可见」目前只有一篇评论文章支持，且对象是 TV 正片，**不能写成 OP 的特征**。建议把方案里那句改成「正片战斗被评论描述为……」。

**从样张归纳（仍属目视，非出版方说法）**

- 线条：细线为主，人脸用排线加深；没有看到「整体粗犷」的线。
- 网点：用得不少（衣物、墙面、头发），既有细网也有粗网。
- ベタ：比例跨度很大，从约四成画面到几乎为零，用来区分压迫场面和静场。
- 彩色：封面是全彩；**内页彩页的有无和数量未证实**（样张全是黑白）。
- 整体气质：「冷白底 + 局部重黑」，静场极空，压迫场极黑。

**二手描述及其与样张的冲突**

- 韩文粉丝 Wiki（NamuWiki，「모리이 시즈키」条目）据搜索摘要称：森井笔线粗而粗糙、网点用得少、以墨（黑）为主、黑白对比强；分格和构图大胆。[摘] https://en.namu.wiki/w/%EB%AA%A8%EB%A6%AC%EC%9D%B4%20%EC%8B%9C%EC%A6%88%ED%82%A4 （本次直接打开返回 403，原文未读到）
- 其中「网点少、线粗糙」与上面 3 个样张**不符**；「黑白对比强、构图大胆」与 p.254 相符。这是可随意编辑的 Wiki，可信度低于目视样张。
- 读者评论（[摘]，BookLive / ブクログ 等摘要）：「ギルガメッシュとエルキドゥの激突。迫力の描写。」（旧版第 2 卷）；新装版第 5 卷「監督役と死徒の戦い……迫力があって」。属主观评价。

**未证实**：内页彩页的数量和位置；新装版是否改动内页（公告只提封面和草图）；森井本人关于画法的访谈。

## 2. 事实：OP / ED / MV 中的「漫画 / 纸面」手法实例

本节不写时间码，本次没有逐帧核对任何视频。

### 2A. 手法有来源的 OP / ED / 片头实例（6 个）

**A1. ジョジョの奇妙な冒険（2012）第 1 部 OP「ジョジョ ～その血の運命～」**
- 制作：神風動画；OP 导演水崎淳平，演出吉邉尚希。[核] https://cgworld.jp/feature/jojo-anime.html
- 手法（均 [核]，同上）：
  - 「原作の漫画のコマからキャラクターが動き出し、スクリーントーンを使ったモノクロの漫画調と色の付いたカラーのセル調のキャラクターが行き交う」。
  - 做了两种排线纹理，一种粗而潦草，一种细密。
  - 轮廓线准备三种粗细，「線の太さの強弱は、グレースケールのマスクを用いて AE 上で調整」。
  - 网点用 Photoshop 制作，速度线/效果线素材用 CLIP STUDIO PAINT 生成。
  - 「ズキュゥゥゥン」拟声字「１文字ずつ 3D 空間内に配置」。
  - 没有纸面分镜，先在 After Effects 里按临时人声做视频分镜（V コンテ）。
  - 全片只有那颗子弹做成写实质感。
- 曲名与作曲背景 [摘]：https://www.famitsu.com/news/202212/29287589.html ；获 CEDEC AWARDS 2013 视觉艺术部门优秀奖 [摘] http://atmarkjojo.org/archives/2776.html

**A2. ジョジョの奇妙な冒険 ストーンオーシャン（2021）OP「STONE OCEAN」**
- 制作：神風動画；OP 导演水﨑淳平，CG 导演宇都宮隆文，美术导演中野友愛。[核] https://cgworld.jp/article/jojo-kamikaze-2303.html
- 手法（均 [核]，同上）：
  - 美术导演加入网点风格和「カケアミ」（交叉排线）风格的处理。
  - **网点在旋转时会闪烁**，团队边看合成后的画面边调整网点密度和位置。
  - 「ライティングによる影を加えない」，以减轻 CG 感。
  - 近景加排线和肌肉线，远景减少线条，并把眼部压暗，以控制信息密度。
  - **背景高饱和色按鼓点节奏切换**。
  - 开场镜头复刻原作扉页。
  - 合成用 After Effects。
- 歌曲信息 [摘]：https://natalie.mu/music/news/455415

**A3. THE FIRST SLAM DUNK（2022，剧场版）片头**
- 歌曲：The Birthday「LOVE ROCKETS」。监督（兼编剧）井上雄彦，演出宮原直樹。[核] https://www.cinematoday.jp/news/N0135142
- 手法 [核]：
  - 湘北队员以「鉛筆のようなタッチ」呈现，走路场面约 80 秒，使用动作捕捉；井上从一开始就有完成图草图。（cinematoday，同上）
  - 「真っ白な空間に……宮城リョータが鉛筆のタッチで描かれていく」，贝斯响起后队员逐一出现。https://number.bunshun.jp/articles/-/856954
- 注意：这是剧场版片头，不是 TV OP；具体制作方法被称为「企業秘密」。

**A4. チェンソーマン（2022）第 11 话 ED「バイオレンス」（女王蜂）**
- ED 监督 Kamata；3DCG 由 jitto 制作（CG 导演高野直樹）。[核] https://cgworld.jp/article/298hs-chainsaw.html
- 手法（均 [核]，同上）：
  - **全片单色**。「あえてカラーで制作後、カラーグレーディングを施してモノクロにする」，理由是一开始就渲染单色无法判断颜色是否正确。
  - 调色不是单纯降饱和，而是「特定の色域を転ばせる」，最后做成 LUT 交给摄影（合成）。
  - 人物为手绘，一拍二（12 张/秒）；3DCG 背景为一拍一（24 张/秒），两者错位的地方要单独处理。
  - 用了动作捕捉，合成软件为 Nuke。

**A5. BLEACH 千年血戦篇（2022）第 1 季 OP「スカー」（キタニタツヤ）**
- 分镜和演出由田口智久担任（本人 X 发文）。[摘] https://x.com/TAGUCHITOMOHISA/status/1582038897621487616
- 手法 [核]：田口称，为与前作区分，以护廷十三队的队花为母题，「色数を絞った演出」；以マゼンタ为基调色，并把嘉百合设为一护的花。https://ja.wikipedia.org/wiki/BLEACH_%E5%8D%83%E5%B9%B4%E8%A1%80%E6%88%A6%E7%AF%87 （Wikipedia 注明出处为週刊少年ジャンプ 2022）
- 说明：这是**限色**手法，不是漫画化手法。归入本节是因为它可作「单墨 + 一色」的参照。

**A6. 天幕のジャードゥーガル（2026）ED「星」（女王蜂）**
- 分镜和演出：青瀬きいろ；原画：森本翼。[摘] https://x.com/AOSE_KIIRO/status/2100073203855138841
- 手法：
  - 本人称「透明水彩で、一枚ずつ仕上げました」，制作花絮显示是在铅笔原画上用笔刷逐层上色。[摘] 同上
  - 「完全手作業」，花絮由 Science SARU 官方 X 公开。[核] https://times.abema.tv/articles/-/10273582

### 2B. 邻近参考（正片、剧场版或非日本作品，手法有来源）（6 个）

**B1. ピンポン THE ANIMATION（2014）正片：分屏**
- 「画面が細かく分割される『スプリットスクリーン』という手法が多用」，评论者认为这是「コマ割によって時間の流れを見せていく漫画の手法を映像に落とし込んだ」。[核] https://realsound.jp/movie/2021/08/post-828165.html （成馬零一，2021-08-04，评论者观点）

- 押山清高：「わざと人間くさい線を残そうとしました」；「本来は……汚れ線や下描き線を消してしまいますが、基本的に残しています」；「体の裏側にある下描き線もあえて残している」。职员表里因此写作「原動画」。[核] https://mantan-web.jp/article/20240726dog00m200073000c.html

**B4. Spider-Man: Into the Spider-Verse（2018，美国）：印刷感**
- 手法（均 [核]）：

  - 动画大多为一拍二，有时一拍三。

## 3. 解读（基于第 1、2 节，属分析判断，不是来源说法）

**3.1 适合 PROVANT 高能量、重节奏段落的手法**（对应方案 E02 / E04 / E07 / E09 / E11）

1. **「网点黑白 ↔ 彩色赛璐珞」按拍切换**（A1）。切换本身就是节奏事件，与方案里「颜色作为能量标记」（E05 后半、E07、E11 回色）一致，也可以缩短成 1–2 帧的闪切，用在重拍上。
2. **背景色块跟鼓点跳**（A2）。PROVANT 低频重，切换点可以落在底鼓上，而不必切镜头。这符合方案「格子在一句内不动」的规则：动的是色，不是格。
3. **一拍二/一拍三 + 套色错位代替动态模糊**（B4、A4 里人物一拍二）。现成动画素材本身带动态模糊和柔光，用分帧（Posterize Time）配合 RGB 错位，能把「视频感」改成「印刷感」，而且错位量可以跟音量包络走。
4. **大面积ベタ压画面**（strange Fake p.254 目视样张）。这是本作漫画版自己的语汇，而 E07、E11 恰好是全曲低频最重的两段。用它，比通用的「漫画滤镜」更有本作的味道。
5. **分屏/碎格表现「同一时刻」**（B1、B4 Panelization）。适合短促的过门段（E04、E09）：分格是把同一瞬间拆开，不是讲顺序。

**3.2 适合安静段落的手法**（对应方案 E03 / E06 / E12，以及回忆插入）

1. **白底铅笔线的逐步显现**（A3）、**保留粗糙原画线**（B2）。线条成了画面主角，与 E03「让声音的线条自己站着」的意图对应。
2. **纸张或水彩质感**（A6 透明水彩、B5 和纸滤镜）。要注意 B5 的经验：和纸滤镜会增加信息量，所以适合特写，不适合信息已经很满的远景。
3. **大面积留白的静页**（strange Fake p.280 目视样张：雨中、细线、干笔旁白框）。可直接作为 E06 白场单格的版面原型。
4. **止め絵 / 一张画定格**（B6）。比冻结一帧视频更有「刻意停下」的意味，适合放在 E06 转折窗口或 E12 的尾音。

**3.3 风险与注意（从来源推出的技术判断）**

- **网点闪烁**：A2 明确说网点在旋转时会闪。因此在推拉或旋转的格里，网点不要跟着素材层变换，应锁定在屏幕或格框坐标上，并按格子大小调点径。这与方案里「点径跟着格子尺寸走」一致。
- **先彩色再转单色**：A4 的做法（先在彩色下调好，再用调色和 LUT 转单色，并可单独推动某个色域）与方案「去色后选择性回色」是同一思路，可以直接借用。
- **线条粗细靠蒙版调**：A1 在 AE 里用灰度蒙版调线宽，说明「主体线粗、背景线细」在合成阶段就能做，不必每个素材分别调参数。
- **限色而非全彩**：A5 证明「少色」本身就能成为一套风格。全片如果只留一个强调色（例如与令咒有关的红/マゼンタ），比各段各自回色更统一。这只是审美判断，需要试帧确认。
- **对官方 OP 的定位**：见第 0 节。不宜把「黑白冲击帧」当作 OP 已有风格来对齐，它目前只有评论文章对正片的描述作支撑。

## 4. 建议：5 套可组合的风格方案

以下是建议，不是事实。参数是起点，需要在 AE 里单帧验证（参照现有漫画风格链 v7）。段落编号沿用 `AMV_DESIGN_PLAN_v1.md`。

### S1「墨压」：高对比ベタ + 集中线 + 一拍二

- **用于**：E07、E11（低频最重），以及 E09 的一记冲撞。
- **做法**：
  - 阈值化，让暗部大面积并入纯黑ベタ，黑块边缘加颗粒或喷溅状虚边。
  - 重拍上叠集中线（2–3 帧）。
  - 素材按一拍二分帧，用 RGB 通道 1–3 px 的错位代替动态模糊。
  - 不用 Glow。
- **参考来源**：strange Fake p.254 目视样张；B4 Spider-Verse（错位、分帧）；A4 Chainsaw ED11（人物一拍二）；A1 JoJo（效果线素材）。

### S2「网点碎格」：密格 + 网点 + 排线

- **用于**：E04、E08，以及 E05 的分句段。
- **做法**：
  - 多格并置，格线在拍点上切开。
  - 格内灰阶转成点网（点径按格子大小走，锁定在屏幕坐标），暗部叠排线纹理，准备粗、细两种（A1）。
  - 格内运镜幅度小。
- **参考来源**：B4 Panelization；B1 ピンポン分屏；A1 两种排线纹理；A2 网点闪烁的教训；strange Fake p.20 目视样张（粗网 + 细网 + 排线并用）。

### S3「单墨一色」：黑白 + 一个强调色

- **用于**：E05 第 4 句开始回色的过渡，以及 E02 里的令咒、宝具高光。
- **做法**：
  - 先在彩色状态下调好，再整体转单色，只把一个色域（红/マゼンタ）留下或推高。
  - 背景色块可以跟底鼓切换。
  - 也可以按拍在「网点黑白」和「彩色」之间闪切。
- **参考来源**：A4（彩色制作后转单色、单独推动色域、LUT）；A5（限色、マゼンタ基调）；A2（背景色跟鼓点）；A1（黑白与彩色切换）。

### S4「铅笔纸面」：原画线 + 纸纹

- **用于**：E03、E12，以及回忆或抒情插入格。
- **做法**：
  - 提取边缘后去掉填色，线条做成铅笔灰并保留抖动和断线。
  - 底色为纸白，纸纹透明度要低（方案里定的 6–12%）。
  - 线条可以从无到有逐步显现，不加网点。
  - 只给特写用，远景不用（B5 的经验）。
- **参考来源**：A3 THE FIRST SLAM DUNK（白底铅笔笔触）；B2 ルックバック（保留下描き线）；A6 ジャードゥーガル（铅笔原画 + 透明水彩）；B5 モノノ怪（和纸滤镜、去掉影子）。

### S5「白场止め絵」：单格留白 + 定格

- **用于**：E06（全曲转折窗口），以及 E12 的最后一格。
- **做法**：
  - 一格，大面积留白，主体只有细线和极淡的网。
  - 文字或旁白框用干笔黑块。
  - 画面完全静止，止め絵的意味来自绘画感，不是暂停的视频帧。
- **参考来源**：strange Fake p.280 目视样张（雨中、留白、干笔旁白框）；B6 出﨑統ハーモニー止め絵。
