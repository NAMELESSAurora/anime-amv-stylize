# 漫画黑白风格（G11 旧版）交接说明

## 1. 风格意图
- 画面"变成漫画页"的一瞬：**格内**是去色的灰阶照片感画面（保留发丝细节，不做硬阈值），**格外的纸面**是黑白网点（AM 连续网点），从画面四边向中心逐渐变淡，中心是干净纸白。
- 全片唯一颜色：瞳孔里的**锈色倒影**（rust accent）。其余全部去色。
- 网点固定在纸面/屏幕坐标上，不随镜头推拉、平移而移动。
- 参考：`ref/old_G11_f62.png`（旧版渲染第 62 帧）、`ref/old_G11_f62_zoom*.png`（放大）、`ref/user_reference.png`（用户选定的参考截图）。

## 2. 两套参数
| 项目 | 旧 G11 参考值（代码实测） | 推荐生产值（团队确定的 4K 值，脚本默认） |
|---|---|---|
| 纸面网点 | AM 圆点，45°，屏幕坐标，二值 0/255 | 同左：AM 连续网点，45°，固定在纸面坐标 |
| 网点间距 pitch | 6 px @1080p（`cell=6`） | 20 px @4K / 10 px @1080p（= 20 × 高/2160） |
| 网点大小 | 半径 ∝ 暗度：`d/(cell·0.7071) < (1−g/255)^1.0` | 网点面积 = 暗度 × 渐变权重 × pitch² |
| 最小网点 | 无 | 直径 < 3 px @4K（1.5 px @1080p）的点删掉，避免灰雾 |
| 边→中心渐变 | **代码里没有**，来自输入画面纸张本身的暗角（纸亮度：中心≈179，角落≈80）【推断】 | 显式径向渐变：归一化半径 < 0.45 完全干净，0.45→1.15 smoothstep 渐强（0.45/1.15 是建议默认值，可调） |
| 纸面墨量（f62 实测） | 中心区 ~22%，边缘 42–74%，格外总计 37.8% | 测试帧格外总计 32.5%（中心 0%） |
| 格内 | 灰度 + 对比 1.1（围绕 128），无网点、无颗粒 | 同左 + 轻颗粒：2–3 px @4K（默认 2.5 px，强度 std 6 级，建议值） |
| 头发 | 由上式自然保持深色 | 深色但不压死，保留发丝；格内**不要**大片纯黑 |
| 锈色瞳孔 | 见第 3 步 | 同左，唯一彩色 |

## 3. 处理流程（旧版，参数均来自 `glitch_pass.py.bak_audit` / `filters.py`）
1. 灰度：`g = cv2.cvtColor(BGR→GRAY)`。
2. **格外纸面网点**：`halftone(g, cell=6, angle=45, gamma=1.0)`；坐标 `u = x·cos45 + y·sin45, v = −x·sin45 + y·cos45`，每格中心距离 `d`，`d/(cell·0.7071) < (1−g/255)` 处为黑墨（0），否则纸白（255）。全帧计算，屏幕坐标固定。
3. **格内**：面板遮罩 = max(遮罩视频 G, B) 通道，膨胀 3×3；格内像素 = `clip((g−128)·1.1+128)` 灰度。格内不打网点（`face_safe: true`）。
4. **锈色瞳孔**：遮罩视频 R 通道（瞳孔倒影处的软边圆盘，覆盖文件来自 `masks/override`），减去歌词覆盖。颜色 = `planet_retint(mode='rust')`：BGR LUT = (0.35g, 0.55g+10, 0.95g+25)；低频噪声（种子 21，1/40 分辨率，三次插值放大）>0.4 处 ×0.65；再 `mute(k=0.35)`：65% 锈色 + 35% 灰度。按 R 遮罩软混合。
5. **格框**：由渲染器画的黑框，经第 2 步网点化（黑=满墨）/ 第 3 步保持，未单独处理。
6. **歌词卡片**：遮罩视频里歌词覆盖 alpha（三通道最小值 >3）从原始干净帧恢复 → 卡片保持米色原样。
7. 时间：G11 事件 185.829 s → 186.921 s，30 fps 下 33 帧，作为定格（2 拍）；之后接白闪。
8. 编码：libx264 preset medium **crf 17**，yuv420p，30 fps，AAC 320k → 实测视频 30.4 Mbps @1080p。

## 4. 输入 / 输出
- 脚本 `manga_bw_g11.py`（仅 numpy + opencv，无项目依赖）：
  ```
  python3 manga_bw_g11.py IN.png OUT.png [--panel x,y,w,h | --panel-mask m.png | --margin-only]
         [--accent rust_mask.png] [--protect text_mask.png] [--pitch PX] [--seed N] [--legacy]
  ```
  - 默认 = 生产值（pitch 随分辨率缩放）；`--legacy` = 旧 G11 原样。
  - 不给面板 = 整帧当作格内（无网点）。`--accent` 为灰度软遮罩；`--protect` 区域从原图恢复（歌词等）。
  - 视频：逐帧处理；`--seed` 用帧号可得到流动颗粒，固定则颗粒静止。
- 测试素材：`ref/test_input_G11_base_f62.png`、`ref/test_panel_mask.png`、`ref/test_accent_mask.png`、`ref/test_protect_lyric_mask.png`。
- 对比图：`comparison_old_vs_script_f62.jpg`（旧渲染 / `--legacy` / 默认生产值，下排为放大）。
  `--legacy` 对旧渲染第 62 帧：PSNR 36.8 dB，平均误差 2.57/255（差异主要是旧片 crf 17 压缩噪点）。

## 5. 已知弱点
- 旧版 6 px 细网点在压缩下糊成灰（crf 17 时中段帧约 10% 像素变成中间灰）。4K 请用随分辨率缩放的更粗 pitch（20 px @4K），并给码率下限（4K 母版 crf 14 / ≥60 Mbps；1080p 测试 ≥15 Mbps），可加 `-tune grain`。
- 旧版的边缘渐变依赖输入纸张的暗角；纸面平的画面不会有渐变 → 生产版用显式径向渐变。
- 旧版网点公式在暗度 >~0.7 时点会连成网，角落接近满墨。

## 6. 不要做
- 格内不要硬三级网点（10/20/30% 量化）或大面积纯黑（团队已否决 tone_v2 方案）。
- 不要用人脸遮罩 / 人脸检测。
- 凪（Nagi）的头发保持蓝黑 / 接近黑，但不要压死，保留发丝。
- 网点不要跟随画面移动、旋转或加运动模糊，固定在纸面上。
- 除锈色瞳孔外不加其他颜色。
